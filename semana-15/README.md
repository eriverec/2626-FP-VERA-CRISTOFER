# Agenda Telefónica de Contactos 📱

Este repositorio contiene un programa en Python desarrollado para cumplir con la tarea **"2626-UEA-L-UFB-026-A_ (Semana 15)_ Tarea - Funciones, Colecciones y Archivos"**. 

## Descripción del Proyecto

El objetivo de este programa es resolver el problema cotidiano de organizar información de contactos. Utiliza un **diccionario** de Python como colección de datos principal, donde el nombre del contacto actúa como clave y el número de teléfono como valor. 

## Funcionalidades Principales

El script interactivo a través de consola permite realizar las siguientes acciones:
- **Agregar:** Insertar nuevos contactos (nombre y teléfono) al diccionario.
- **Mostrar:** Recorrer la colección y mostrar en pantalla todos los contactos guardados de manera clara y amigable.
- **Buscar:** Consultar un contacto específico por su nombre para obtener su número telefónico.
- **Eliminar:** Borrar el registro de un contacto existente en la agenda.

## Estructuras de Datos Utilizadas
- **Diccionarios (`dict`):** Se utilizó para almacenar los datos debido a su eficiencia al buscar y relacionar elementos (clave-valor).

## Requisitos
- Python 3.x instalado en tu computadora.

## Cómo ejecutar el programa

1. Clona este repositorio o descarga el archivo `agenda_contactos.py`.
2. Abre tu terminal o línea de comandos.
3. Ubícate en la carpeta donde guardaste el archivo.
4. Ejecuta el siguiente comando:
   ```bash
   python agenda_contactos.py
   ```
